# Stokisha

**Stokisha** is a mobile-based Inventory and Expense Management System developed using **Swift** for iOS and powered by a **Flask** + **MySQL** backend. It is designed to help individuals and small businesses manage stock levels, track purchases, and monitor expenses efficiently.

## Project Status

Completed – Ready for demo, deployment, or further enhancement.

## Features

- Real-time inventory tracking  
- Daily expense and purchase recording  
- Visual reporting and insights  
- Role-based access for secure user management  
- Seamless mobile-backend integration via REST API

## Tech Stack

- **Frontend**: Swift (UIKit or SwiftUI)  
- **Backend**: Flask (Python)  
- **Database**: MySQL  
- **API**: RESTful JSON APIs over HTTPS
